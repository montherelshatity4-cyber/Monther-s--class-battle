# Monther's Class Battle

A professional classroom team competition game for English classes built with React and Vite.

## Overview

This project is the foundation for a future classroom game experience with:

- Teacher Control Panel
- Student / Projector Screen
- Team management
- Score system
- Grammar, vocabulary, and speaking rounds
- Final Battle and question bank

## Current version

The app includes the first two screens requested:

1. Welcome screen with large START THE BATTLE button
2. Team Setup screen with four colored team cards and name inputs

## Run locally

1. Install dependencies:

```bash
npm install
```

2. Start the development server:

```bash
npm run dev
```

3. Open the app in your browser:

```text
http://localhost:5173
```

## Build for production

```bash
npm run build
```

## Preview production build

```bash
npm run preview
```
